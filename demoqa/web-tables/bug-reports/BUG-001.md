# BUG-001: Deleting Records Reappear in Web Tables

## Environment
- Website: https://demoqa.com/radio-button
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sonoma 14.3 (23D56)

## Steps to Reproduce
1. Open the Elements page.
2. Open the Web Tables page.
3. Delete one of the three existing records.
4. Delete one of the two remaining records
5. Observe the records displayed in the table.

## Expected Result
The selected record should be deleted, and the remaining records should stay unchanged.

## Actual Result
After deleting a record, a previously deleted record reappears in the table. The table does not allow all three original records to be deleted.
