# TC-001: Verify File Download

## Environment
- **Website:** https://demoqa.com/upload-download
- **Browser:** Google Chrome 155.0.8059.40 (arm64)
- **Operating System:** macOS Sequoia 15.3 (24D2059)

## Steps to Execute
1. Open the Upload and Download page.
2. Click **Choose File** and select a file from the computer.
3. Click **Download**.
4. Open the downloaded file.
5. Compare the downloaded file with the selected file.

## Expected Result
The download button should download the file specified by the website's intended functionality.

## Actual Result
The download button downloaded a predefined sample image `sampleFile.jpeg` instead of the file selected using choose file.
