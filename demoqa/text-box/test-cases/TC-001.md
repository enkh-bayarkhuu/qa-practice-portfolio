# TC-001: Verify the Full Name Field Accepts a Single Name

## Environment
- Website: https://demoqa.com/text-box
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Execute
1. Open the Elements page.
2. Open the Text Box page.
3. Type `Adam` in the full name field.
4. Fill in the other fields.
5. Click Submit.

## Expected Result
It should ask the user to enter their full name instead of accepting only a first or last name. 

## Actual Result
The form accepts `Adam` as the full name and displays it after submission.
