# BUG-003: The full name field accepts a single-letter name

## Environment
- Website: https://demoqa.com/text-box
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Reproduce
1. Open the Elements page.
2. Open the Text Box page.
3. Type `f` in the Full Name field.
4. Fill in the other fields.
5. Click Submit.

## Expected Result
The form should ask the user to enter a valid full name instead of accepting a single letter.

## Actual Result
The form accepts `f` as the full name and displays it after submission.

## Severity
Low (tentative)

## Status
Needs investigation
