# API Testing Practice

This folder contains my ongoing practice with API testing using Postman and public APIs.

# What I've Practiced So Far

- Sending GET, POST, PATCH, and HEAD requests.
- Adding and testing custom request headers.
- Sending different request body formats, including JSON, form URL-encoded, and raw text.
- Checking response status codes, headers, and body content.
- Testing empty, invalid, and unexpected inputs.

# Tools and APIs

- **Postman:** Creating and sending API requests and reviewing responses.
- **Postman Echo:** Practicing request headers and different request body formats.
- **JSONPlaceholder:** Practicing HTTP methods and API response validation.

# Test Cases

Each test case is documented in Markdown with steps to execute, expected results, and actual results.

More test cases will be added as I continue learning and exploring API testing :)
