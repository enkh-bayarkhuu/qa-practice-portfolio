# qa-practice-portfolio
Manual QA testing practice, including test cases, bug reports, and software testing documentation :)

## About This Project

This repository documents my journey learning manual QA testing. I'll use it to practise writing test cases, exploring different testing scenarios, documenting bugs, and keeping track of what I learn along the way.

I'm building this portfolio to develop practical QA skills, gain experience with testing tools and techniques, and better understand how software testing works in real-world situations.

## Objectives

- Practise writing clear and structured test cases.
- Explore different testing scenarios.
- Learn how to identify, document, and report potential bugs.
- Record test results and compare actual behavior with expected results.
- Explore tools and techniques used in software quality assurance.

## Tools & Platforms

- **DemoQA:** Practising manual testing.
- **Notion:** Organizing test cases, tracking test results, documenting bugs, and keeping learning notes.
- **GitHub:** Organizing and sharing my testing portfolio.
