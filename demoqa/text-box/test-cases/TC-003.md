# TC-003: Verify the Full Name Field When Entering a Symbol

## Environment
- Website: https://demoqa.com/text-box
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Execute
1. Open the Elements page.
2. Open the Text Box page.
3. Type `+` in the Full Name field.
4. Fill in the other fields.
5. Click Submit.

## Expected Result
The form should handle a symbol only input according to its requirements.

## Actual Result
The form accepts `+` as the full name and displays it after submission.
