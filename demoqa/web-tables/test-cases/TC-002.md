# TC-002: Verify Email Address Validation

## Environment
- Website: https://demoqa.com/webtables
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sonoma 14.3 (23D56)

## Steps to Execute
1. Open the Elements page.
2. Navigate to the Web Tables page.
3. Click the Add button.
4. Enter a@e.com in the Email field.
5. Fill in the remaining fields with valid information.
6. Click Submit.

## Expected Result
The form should validate the email address according to its requirement.

## Actual Result
The form accepts a@e.com without verifying whether the email address exists.
