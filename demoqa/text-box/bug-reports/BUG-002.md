# BUG-002: The Full Name field accepts an empty value

## Environment
- Website: https://demoqa.com/text-box
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Reproduce
1. Open the Elements page.
2. Open the Text Box page.
3. Leave the Full Name field empty.
4. Fill in the other fields.
5. Click Submit.

## Expected Result
The form should ask the user to enter their full name instead of accepting an empty field.

## Actual Result
The form accepts the empty Full Name field and displays the submitted information after submission.

## Severity
High (tentative)

## Status
Needs investigation
