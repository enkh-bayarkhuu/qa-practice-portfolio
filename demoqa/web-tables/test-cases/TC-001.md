# TC-001: Verify How the First and Last Name Fields Handle Invalid Characters

## Environment
- Website: https://demoqa.com/webtables
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Execute
1. Open the Elements page.
2. Navigate to the Web Tables page.
3. Click the Add button.
4. Enter 2 in the First Name field.
5. Enter &* in the Last Name field.
6. Fill in the remaining fields with valid information.
7. Click Submit.

## Expected Result
The form should handle the first and last name fields according to their requirement.

## Actual Result
The form accepts 2 as the first name and &* as the last name without displaying any validation errors.
