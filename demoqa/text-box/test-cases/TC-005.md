# TC-003: Verify Address Fields When Left Empty

## Environment
- Website: https://demoqa.com/text-box
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Execute
1. Open the Elements page.
2. Open the Text Box page.
3. Leave the Current Address and Permanent Address fields empty.
4. Fill in the other fields.
5. Click Submit.

## Expected Result
The form should handle empty address fields according to its requirements.

## Actual Result
The form accepts empty address fields and submits the information.
