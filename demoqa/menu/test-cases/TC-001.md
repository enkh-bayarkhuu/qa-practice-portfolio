# TC-001: Verify Menu Item Behavior

## Environment
- **Website:** https://demoqa.com/menu
- **Browser:** Google Chrome 155.0.8059.40 (arm64)
- **Operating System:** macOS Sonoma 14.3 (23D56)

## Steps to Execute
1. Hover over Main Item 1 and try clicking it.
2. Hover over Main Item 3 and try clicking it.
3. Hover over Main Item 2 and observe its behavior.
4. Compare how the three menu items respond.

## Expected Result
Each menu item should respond as intended when hovered over or clicked.

## Actual Result
Main Item 1 and Main Item 3 do not respond when hovered over or clicked. Main Item 2 displays submenu options when hovered over.
