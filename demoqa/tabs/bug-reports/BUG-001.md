# BUG-001: More Tab Is Not Clickable

## Environment
- Website: https://demoqa.com/tabs
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Reproduce
1. Open the Tabs page.
2. Click the Origin and Use tabs to view their concent
3. Click the More tab.
4. Observe whether the tab responds.

## Expected Result
Clicking the More tab should display its related content, unless the tab is intentionally disabled.

## Actual Result
The More tab does not respond when clicked, and no additional content is displayed.
