# TC-001: Verify Links That Open in New Tabs

## Environment
- Website: https://demoqa.com/links
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sonoma 14.3 (23D56)

## Steps to Execute
1. Open the Elements page.
2. Navigate to the Links page.
3. Click the first link labeled **Home**.
4. Return to the original tab.
5. Click the second link, which also opens a new tab.
6. Compare the URLs and content of both tabs.
7. Check the names of both tabs.
8. Reload the Links page and repeat the test.

## Expected Result
Both links should direct users to their intended destinations.

## Actual Result
Both links opened the same destination. However, the second tab's name started with Home, followed by five letters that changed each time the page was reloaded.
