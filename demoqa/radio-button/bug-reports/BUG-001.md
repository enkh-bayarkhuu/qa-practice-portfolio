# BUG-001: No Radio Button Is Not Selectable

## Environment
- Website: https://demoqa.com/radio-button
- Browser: Google Chrome 155.0.8059.40 (arm64)
- Operating System: macOS Sequoia 15.3 (24D2059)

## Steps to Reproduce
1. Open the Elements page.
2. Open the Radio Button page.
3. Try to select the No option.

## Expected Result
The user should be able to select No and see a message confirming the selection.

## Actual Result
The No option cannot be selected, and no confirmation message appears. The Yes and Impressive options work.
